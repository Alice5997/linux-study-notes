## 前置准备模块（对应 058_尚硅谷_大数据定制篇_Shell 快速入门）

> 模块执行目录：家目录 `~`

### 核心知识点

1. Shell 是 Linux 命令解释器，接收用户指令转交内核执行；CentOS Stream9 默认解释器`/bin/bash`
2. Shell 脚本：批量整合多条 Linux 命令，实现自动化操作
3. 查看系统支持的 Shell 类型、当前使用 Shell

### 实操命令

```
# 查看系统全部可用解释器
cat /etc/shells

# 查看当前登录使用的shell
echo $SHELL

# 创建当日统一练习目录
mkdir -p ~/day08_test01
cd ~/day08_test01
```

### 避坑标注

> ⚠️Shell 脚本首行必须写`#!/bin/bash`，用于指定脚本解释器，不可省略；# 单独出现为注释，#! 是特殊声明，不属于注释。

## 模块 2 Shell 环境变量（对应 060_尚硅谷_大数据定制篇_Shell 环境变量）

> 模块执行目录：`~/day08_test01`

### 核心知识点

1. 环境变量属于系统全局变量，所有 Shell 会话均可读取，不可随意修改
2. 常用内置环境变量：\(USER、\)HOME、\(PATH、\)SHELL

### 实操命令

```
vim env_var.sh
```

脚本内容：

```
#!/bin/bash
echo "当前登录用户：$USER"
echo "用户家目录：$HOME"
echo "系统命令查找路径：$PATH"
echo "当前使用解释器：$SHELL"
```


### 避坑标注

> 调用变量推荐使用`${变量名}`格式，拼接字符串时不会出现识别歧义。

## 模块 3 位置参数变量 $n（对应 061_尚硅谷_大数据定制篇_Shell 位置参数变量）

> 模块执行目录：`~/day08_test01`

### 核心知识点

1. `$0`：脚本自身文件名
2. `$1 $2 $3...`：传入脚本的第 1、2、3 个参数
3. 参数编号≥10 时，必须使用大括号 `${10}`，不可直接写 $10

### 实操命令

```
vim pos_param.sh
```

脚本内容：

```
#!/bin/bash
echo "脚本文件名：$0"
echo "第一个传入参数：$1"
echo "第二个传入参数：$2"
echo "第十个传入参数：${10}"
```

授权并传入多个参数测试：

```
chmod u+x pos_param.sh
./pos_param.sh a b c d e f g h i j
```

执行输出示例：

```
脚本文件名：./pos_param.sh
第一个传入参数：a
第二个传入参数：b
第十个传入参数：j
```

## 模块 4 预定义变量 $# $* $@ $?（对应 062_尚硅谷_大数据定制篇_Shell 预定义变量）

> 模块执行目录：`~/day08_test01`

### 核心知识点

表格

| 预定义变量 | 作用说明                             |
| ----- | -------------------------------- |
| `$#`  | 传入脚本的参数总个数                       |
| `$*`  | 将所有参数合并为一整个字符串                   |
| `$@`  | 每个参数独立分开存储，循环遍历使用                |
| `$?`  | 上一条命令执行返回状态码；0 = 执行成功，非 0 = 执行报错 |

### 实操 1：修改 pos_param.sh，追加预定义变量输出

```
vim pos_param.sh
```

追加内容，完整脚本：

```
#!/bin/bash
echo "脚本文件名：$0"
echo "第一个传入参数：$1"
echo "第二个传入参数：$2"
echo "第十个传入参数：${10}"

echo "参数总数量 \$# = $#"
echo "全部参数合并字符串 \$* = $*"
echo "参数独立列表 \$@ = $@"
```

运行测试：

```
./pos_param.sh java linux shell mysql
```
![[Pasted image 20260820003835.png]]
### 实操 2：单独测试 $? 返回码（任意目录均可执行）

```
# 正常执行命令，查看返回码
ls /etc
echo $?

# 执行不存在的错误命令，查看返回码
ls /abc123456
echo $?
```

### 避坑标注

> `$*`与`$@`不加双引号时效果近似；双引号包裹后行为完全不同，循环遍历参数优先使用`"$@"`。
